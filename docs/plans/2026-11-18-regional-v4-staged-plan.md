## 0. 一句话现状

**能力面已证明可行**（位置、尺度均可编码进 LLLite），**数据面尚未解决**（干净训练对的量产引擎
还有两条候选路线未校准）；生产管线与此线完全隔离，placement 在生产中仍为禁用状态。

## 1. 背景与目标

- 目标：训练 3.8B（DeltaMix V8，52 层）的 Regional LLLite adapter，输入纯色人形区域图
  （白剪影黑底），把人物硬条件到指定位置与大小；完成后接入单人姿态线 placement 参数面。
- 生产现状：**零改动**。生产 pass 配置（16 步 / denoise 0.25，commit `1c5ee0c`/`a32adea`）
  与本线无关；所有实验权重、数据都在 WSL 训练目录，不进 `~/anima-prod/models` 的生产引用面
  （仅 eval 临时拷贝）。

## 2. 历史轮次（v1–v3）与 E 系列结论

| 轮次 | 数据 | 训练 | 结论 |
|---|---|---|---|
| v1 | 1464 对（control↔target 错位） | 8000 步 loss≈0.136 | 作废（对齐 bug） |
| v2 | 1464 对，rembg(isnet-anime) 从 target 分割 control | 8000 步 loss≈0.134 | 位置控制证伪：condition 剪影 cx std **0.043**（位置近常量）→ shortcut learning，剪影只控姿态/外形 |
| v3 | 5853 对（原 1464 + 同步平移/缩放增广，边缘复制填充） | 12000 步 2h53m loss≈0.101（仅 **2.7 epoch**） | E25 全失败面筛查：极端位置走一半、小主体面积膨胀 4–7 倍、角落双轴全败 |

**v3 数据分布实测（2026-11-18 复采，aug-v3-manifest.json）**：

- cx：mean 0.501 std 0.154，range [0.158, 0.833]，p10–p90 [0.293, 0.708]
- cy：std 0.128，range [0.186, 0.799]
- area：mean 0.145 std 0.077，**min 0.060——小于 0.06 的目标零样本**
- 极端 cx（<0.2 或 >0.8）仅 **37 对（0.8%）**；角落组合 334 对

**E25（v3 终权重，14 变体）关键行**：xleft dx+0.161（baseline strength0 为 +0.231）、
xright −0.174、yup dy+0.185、tiny 0.030→gen 0.220（7.3 倍）、corner dx+0.165/dy+0.201、
realc（分布内）dx 0.022、large IoU 0.733、**strength 1.0 无改善（dx 0.148）→ 非欠驱动**。

**E25 的再解读（2026-11-18）**：评估点大多在 v3 训练分布之外（xleft 0.249 < p10 0.293；
tiny 0.030 < min 0.060）。「v3 失败」= 分布外外推 + 极端样本稀少（0.8%）+ 小主体从未覆盖
+ 疑似欠训练（2.7 epoch，社区 Sen-sou 参照 7.6 epoch）——四个可修变量的合集，不是能力证伪。

## 3. 机制认知（多轮问答收口）

- **RS 分域**：管辖域硬（词的区域绑定 + latent 区域初始化——身份隔离可靠的原因），
  内容位置软（E7 默认墙 ~10 个点；E9 拉满全部旋钮仍不够 → RS 位置拉力已到头且无训练抓手）。
- **LLLite regional**：无管辖域，纯全局注意力残差偏置，最软；但**可训练**，上限未知——
  这就是自训的意义（S1 实测它已把位移完成度做到远超 RS 墙）。
- 真正的位置硬约束只存在于采样外/采样中的机械操作（latent 拼贴、inpaint mask）。
- RS 与 LLLite **机制兼容可链式叠加**（双人线现役结构即 RS 采样器 + ModelPatchLoader；
  regional LLLite + RS 的叠加从未测过，留作 v4 后期验证项）。

## 4. 阶段实验（2026-11-18，S 系列）

训练配置全部同 v3（lr 3e-4 / AdamW8bit / cosine / bf16 / LLLite 结构参数一致），
唯一变量 = 数据；评估统一用 E25 模板 graph（912×1216，仅初采样，seed 424242，
rembg isnet-anime，256 网格归一测量）。

### S1 位置能力 overfit —— ✅ 通过

- 数据：30 对 = 2 种子（0773-3 / 0078-3，原生 area 恰为 0.18 → 纯平移零缩放）× 16 点位
  （九宫格 cx{0.22,0.5,0.78}×cy{0.30,0.5,0.70} + 角点 + 随机点），画缘裁切 ≤35% 入 manifest 真值
- 训练：4000 步（~133 epoch），loss 0.0563
- 结果：**验收门（|dx|,|dy|≤0.05）28/30**；|dx| 中位 0.005 / 最大 0.060；面积 0.181 vs 0.18；
  **基线（strength 0）0/30，|dx| 中位 0.273**——跟随来自条件本身，非先验巧合
- 唯二未过：0773-3 左中两点（IoU 0.60/0.66，生成偏大 0.27–0.29）——姿态难度差异，v4 数据需覆盖
- **结论：位置可编码，无结构上限；v3 失败定罪 = 数据分布 + 训练量**

### S2 尺度能力 overfit —— ✅ 通过（≥0.05）

- 数据：18 对 = 3 种子 × 6 档面积 {0.03, 0.05, 0.08, 0.12, 0.20, 0.40}，cx/cy 钉 0.5
- 训练：4000 步，loss 0.0465
- 结果（ratio = gen_area / cond_area；基线 ratio 全线 0.39–6.2）：

| 档 | LLLite ratio | 判定 |
|---|---|---|
| 0.03 | 0.04 / 1.32 / 0.03（rembg 测量，见下修正） | 过画 2–3 倍（视觉修正后） |
| 0.05 | 0.95 / 1.28 / 1.01 | 2/3 过 |
| 0.08 | 0.97 / 1.02 / 1.11 | 3/3 过 |
| 0.12 | 0.92 / 1.06 / 1.04 | 3/3 过 |
| 0.20 | 1.02 / 1.04 / 1.02 | 3/3 完美 |
| 0.34–0.39 | 0.95 / 1.00 / 1.00 | 3/3 完美 |

- **视觉修正（glm-5.3-flash 目检）**：0.03 档三张全部画了居中人物（目检约 6–9% 面积），
  rembg 的 ≈0.001 是**假阴性**——条纹背景干扰分割。真实行为 = 过画 2–3 倍，与 v3 失败同向但更轻
- **结论：尺度可编码；实用下限定为 0.05；0.03 排除出 v4 范围**

### 放置引擎与清理校准（同日晚）

- **S1+S2 链式注入（AnimaLLLiteApply × 2 串联）放置精度 4/4 近乎完美**：
  (0.20,0.30,a0.05)→(0.20,0.30,a0.054)、(0.80,0.70,a0.12)→(0.80,0.70,a0.122)、
  (0.50,0.50,a0.30)→(0.50,0.50,a0.299)、(0.20,0.70,a0.18)→(0.20,0.71,a0.187)
- **背景重绘（denoise 0.45）破坏放置**：clean 列位置/面积全部漂移（最重 cy 0.70→0.31、
  面积 0.18→0.32）→ 该清理参数不可用

## 5. 伪影事件与教训（v4 数据设计的直接输入）

1. **边缘复制填充的条纹被模型学走**：S1 训练目标平移后空出的边缘是最近邻复制条纹，
   overfit 模型在离中心构图时自己画出条纹（主人目检发现「拉伸条纹」；视觉复核确认：
   轴对齐矩形补丁、取色自邻近场景、无损 PNG 亦存在 → 排除传输伪影；30 格约 12 格中度）。
2. **条纹还会腐蚀测量链**：rembg 在重度条纹背景上漏检小人物（S2 0.03 档假阴性）。
   小主体判定一律以视觉抽检兜底。
3. **模糊填充被否**（主人裁定）：训练「剪影外=模糊」会生成只有人物清晰、四周全糊的图，
   与条纹同构的错，只是更好看。
4. **背景重绘 0.45 破坏放置**（见上）→ 低温档未测。
5. **图-景两通道独立学习**（S1/S2 正面证据）：条纹/模糊背景不污染「人物画多大画在哪」
   的学习与测量——这是能力结论在伪影下仍然成立的原因。
6. **流程教训**：任何新数据方法先出 4–8 张校准图 + 视觉复核，过了才允许批量/训练；
   杀错项目的止损以分钟计（S3 杀于 3 分钟、S2R 杀于 1 分钟）。
