### 2.4 inline 图片：array content

原始 entry 48214 的 `model[0].content` 是数组：

```json
[
  {
    "type": "text",
    "text": "下面是群里刚聊的 5 条…
…
本条消息末尾直接附了 1 张图（你能看到原图），需要的话直接看它们，不必调 look"
  },
  {
    "type": "image",
    "data": "<JPEG base64>",
    "mimeType": "image/jpeg"
  }
]
```

同一条的 `data.text` 只是：

```text
[图片 inbound/1793782479412-17b764.jpg]
```

所以必须区分：`data` 的路径摘要、`model` 的文本路径和 inline base64 图片是不同层。普通文本路径仍占多数，inline array 实际有 155 条。

## 7. 证据边界与复查

数据库保存的是 pi-durable model entry，不是完整 provider HTTP 请求体；动态 system、工具列表及当次完整 wire payload 不在本报告断言范围内。

```bash
cd ~/yugang
sqlite3 -readonly var/fish.db "
SELECT json_extract(record,'$.kind'), json_type(record,'$.model[0].content'), count(*)
FROM entries
WHERE json_extract(record,'$.kind') IN
 ('fish.inbound','fish.engage_tick','fish.gif_ingest','fish.worker_round')
GROUP BY 1,2;"

sqlite3 -readonly -json var/fish.db "
SELECT id,conversation_id,record FROM entries
WHERE id IN (48355,48090,44384,48214,43669,48306,48351,44333,47324,45682,48364,48376,48004)
ORDER BY id;"
```

省略号仅用于篇幅节录，可按 entry id 回查完整原始 `record`。
