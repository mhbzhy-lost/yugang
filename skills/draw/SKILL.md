# 画图

## 步骤

1. 把群友的需求压成一句画面描述（去掉"画一张"这类指令词）
2. 跑脚本，把描述和一个颜色传进去：

```bash
node "$YUGANG_SKILL_DIR/draw/scripts/make.mjs" "描述" "#3b82f6" [可选输出文件名]
```

`$YUGANG_SKILL_DIR` 是 skills 根目录。脚本会把 PNG 写进 `$YUGANG_MEDIA_ROOT`，并在 stdout 打印一行：

```
[IMAGE:/绝对/路径.png]
```

3. 把这一行里的路径拿出来，作为 `say` 的 `media` 参数一起发出去。**不要**把这条路径写进 text。

## 约束

- 一次只画一张
- 失败（脚本非 0 退出）就直接说"画崩了"，不要编造路径
- 颜色随便挑一个贴近描述的即可，不用问
