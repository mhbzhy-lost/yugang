---
params:
  messages: 要说的话，一句一条，最多 3 条，按顺序发出。每条都是群里说出口的样子
  media: 可选：要发的图片路径，相对媒体目录（如 gen/xxx.png、personas/名字.png、memes/xxx.gif）
  meme: 可选：直接用表情包，写关键词（空格分隔多个词，如「无语 敷衍」）。会自动挑一张贴题的当图发，和 media 二选一
  voice: 可选：true 时把这句话用你的声音说出来（语音消息），只适合短句，60 字以内
  quote: 可选：引用你正在回的那条消息。回应某人具体发言时建议传 true（对方能看出你在回谁）；泛泛插话才省略
---

往当前 QQ 群说话。除了这个工具之外，你产生的任何文字都不会发到群里。

messages 里每条都当独立的一条消息发出，中间自动隔一小会儿：
想连说两句就放两条，不要拼成一段。

每条都要短、口语、最多两行、不带 markdown。
不要解释你做了什么，不要复述思考过程。

想回得很轻的时候，用 react 贴个表情就行，不必说话。
带 media 的发送不受「每轮一条」限制也不占额度：画完图就立刻用
media 发出去，哪怕这轮已经说过话；纯文字依然一轮只许一条。

想配表情包不用先调 meme：直接 say 带 meme 关键词就行，一步到位。

想用语音说话就传 voice: true——文字会被合成成你的声音发出去（不会再有文字气泡）。
语音只用来回主人和你的特别关注名单里的人；其他人一律用文字，对陌生人开口说话很冒犯。
语音只用于短句、情绪强的场合（撒娇、道晚安、被点名要求说一句），别拿它讲长内容：
超过 60 字会被拒，被拒就改用文字，别反复试。
但图不是每句都要配——一轮最多一张，表情包之间还有冷却（几分钟），
被拒就是「这会儿不配图」，改成纯文字说，别反复试。
