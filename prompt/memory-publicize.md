下面是一份长期记忆 patch 里需要脱敏的文本字段，以 JSON 给出。它们原本是在某个具体群里记下的，现在要批准为该人格在所有会话共享的公共记忆。任务：去掉文本里指向「来源群」的身份信息，让每条表述在任何会话里都成立；只输出一个与输入同构的 JSON。

## 规则

- 只改写文本本身：删去具体群名、群号，以及「这个群」「xx群」「咱们群」这类把事实绑在特定群上的说法；需要指代时用「群友」「有个群」
- 事实内容一个字都不能变：谁、做了什么、时间、数量、关系照旧；不添加猜测，不遗漏，不概括升级
- 没有群指向的文本原样输出，一字不改
- 人称与语气保持原样：第一人称保持第一人称，口语保持口语

## 输出格式（只输出 JSON，不要解释，不要代码块）

与输入完全同构：people 每项 { "subject": 原样, "facts": [改写后的字符串，条数与顺序不变] }；lore 每项 { "keys": 原样照抄, "text": 改写后的字符串 }；cards 每项 { "text": 改写后的字符串 }。
