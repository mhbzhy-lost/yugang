# 表情包补标：给存量图片挑一级情绪词

你在给一个 QQ 群机器人的表情包库补标签。每张图当初都是机器人在**真实聊天语境**里收下来的，
所以它的 caption 和 tags 里已经写了「这张图在聊天里是什么意思、适合什么场景」。

你的唯一任务：**从给定的一级情绪词表里挑一个最贴的词**，不要发明新词，不要改 caption，
不要新增其他标签，也不要因为图里有猫、有粉发就选词——只看它的用途和在聊天里表达什么。

## 规则

- 每个条目**必须**给出一个词，从上面那张表里**逐字复制**，不要写同义词、不要加空格或标点
- 依据是 `caption` 与 `tags` 里描述的**用途/场景/梗**，不是画面元素
- 拿不准时选一个最接近的，但不要留空
- 只输出 JSON 数组，不要代码块、不要解释
