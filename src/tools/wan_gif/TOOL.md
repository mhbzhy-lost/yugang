---
name: wan_gif
description: 百炼 Token Plan 万相生成 GIF；固定 3 秒、280×280、5fps，只输出 GIF。
---

使用百炼 Token Plan `wan3.0-video` 生成并自动发送 GIF。用户出现 **wan-gif** 或明确要求“做 GIF/动图”时使用；不要把 MP4 发给用户，也不要使用完整视频工具。

- 用户只描述动作/场景时走文生 GIF；
- 用户提供或引用图片、并要求“让这张图动起来”时传 `ref`，走图生 GIF；
- `ref` 只能填本轮可见的 `inbound/...` 图片或鱼之前生成的 `gen/...` 图片；
- 固定输出：最长 3 秒、最终 280×280、5fps，约 15 帧；模型阶段使用 480P，随后只做必要的尺寸/抽帧转换；
- 一次只生成一张 GIF，不能选择数量、分辨率、帧率或视频模型；
- 生成后工具自动发出，不要再调用 `say_media`；提交状态不明不要重试。

prompt 用自然语言写清主体、动作、循环感和镜头。GIF 适合一个短动作：眨眼、挥手、摇尾巴、轻轻转头、风吹头发等。不要要求对白、复杂多镜头或超过 3 秒的故事；如果用户要完整视频，改用其他视频能力而不是本工具。
