用远程接口画一张图，或按参考图改图。这是**异步工具**：参数和配置校验通过后立刻返回，后台画完会自动发到群里。
走哪条通道（gpt / wan / qwen / gemini）由主人在 `fish.config.json` 的 `drawRemote.provider` 里热配置——
**你不选通道、不填模型名**；通道能力不同，不支持的参数工具会用回执告诉你，不会偷偷换成别的通道。

## 什么时候用这个工具

- 用户点名 **在线 / 云端 / GPT / Gemini / Wan（万相）/ Qwen** 画图，或明确要「用在线的画」；
- 用户没点名在线画图时默认走本地：动漫 / 角色 / 双人用 `draw`，要 2K 文字海报或自然语言重绘用 `qwen_draw`；
  不要为了「效果更好」擅自替用户换到在线通道；
- 要动图（GIF）用 `wan_gif`，这个工具只出静态图；
- 用户点名的通道和当前通道不一致时你切不过去：如实说明现在用的是哪条通道（回执里会带通道名）。

## 参数怎么填

- `prompt`（必填）：画面描述，自然语言句子，中文英文都行；写清主体、动作、环境、光线、风格。
  4000 字以内（超了回执会说）；想要横版 / 竖版传 `aspect_ratio`，当前是 gpt 通道时改把构图写进描述；
- `images`：参考图路径，传了就是改图 / 图生图。填消息里 `[图片#N inbound/…]` 标签带的路径
  （带不带方括号都行），或你自己画过的 `gen/…`；最多 5 张（qwen 通道最多 3 张），单张 10MB 以内，
  只认 png/jpg/webp（gpt / qwen 通道额外认 gif；gemini 通道参考图合计 15MB 以内）；
- `aspect_ratio`：`1:1` / `3:4` / `4:3` / `9:16` / `16:9`；qwen / wan / gemini 通道生效，gpt 通道忽略（靠 prompt 写构图）。

## 硬规矩

- **异步提交**：回执说已交给在线画师后台绘制后，立刻用 `say_words` 简短告诉群友已经开始画了，不用等出图，也**不要调 `say_media`**（画好后宿主会自动发到群里）；
- 同一个群同时只能有一张远程画图在途，一轮最多成功提交一次；上一张还在画时会直接拒绝；
- 回执说没配置 / 不支持 / 参数问题时，可以改参数后在同一轮重试，或者用 `say_words` 简单说明原因；
- 看不到图的内容就别猜原图长什么样。
