用 Qwen-Image-2.1 画一张图（出图后自动发出）。走的是另一条管线：**自然语言理解 + 真实感 + 文字渲染**，
和 draw（danbooru tag 动漫管线）分工不同。

## 什么时候用这个工具

- 用户消息里出现 **qwen-image** 关键词（大小写不限）——必走本工具，不再用 draw；
- 用户明确要「Qwen 画的」「用 Qwen Image」等同义表达；
- 任务本身是 Qwen 的主场：**图里要有文字**（海报、招牌、带字 meme，中文尤强）、真实感人像/场景、
  高分辨率背景、透明素材；
- 其余画图需求（动漫、角色、双人）默认走 draw，不要抢。

## prompt 怎么写（和 draw 完全不同）

- **自然语言完整句子**，中文英文都行；**不要写 danbooru tag**（`1girl, score_9` 这类词在这里是降级用法，
  score/masterpiece 词完全无效）；
- 主体放句首，再写场景、动作、光线、风格（「一个银发女生穿水手服站在夕阳下的山顶」而不是 tag 罗列）；
- 要图里出现文字时**用引号框住内容**，并写明位置和字体感觉（「木招牌上写着『鱼缸咖啡』，书法体」）；
  引号能明显提高文字准确率；
- 1–3 句为宜，堆太多形容词反而糊。

## 角色与参考图

- **没有角色 LoRA，也不认识新角色**（实测点名遐蝶出图零角色特征）。画词表里的角色 → 用 draw；
  一定要 Qwen 画风的角色 → 用 ref 参考图（先让 draw 画底图再重绘）；
- **ref 是本工具的重绘入口**：2.1 的视觉编码器真的看图，会锚定构图改内容/换风格/提分辨率。
  推荐管线：draw 画底图（1024）→ 本工具 ref=那张图 + resolution=2048 + prompt 写要增强/修改的点。
  ref 沿用参考图比例，resolution 是重绘目标域。

## 参数速查

- ratio：七种官方比例（1:1、4:3、3:4、3:2、2:3、16:9、9:16），默认 1:1；带 ref 时无效（沿用参考图比例）；
- resolution：1024 标准域（约 1MP，快）/ 2048 原生 2K（约一分钟）；默认 1024；
- fast：true 用 turbo 8 步（更快、细节略降），默认质量档 25 步；
- seed：复现同图用，默认随机。

## 边界

- 一轮最多画一次；提交失败不消耗次数，提交状态不明本轮不能重试（和 draw 同规矩）；
- 看不到图的内容就别猜原图长什么样；失败时把错误告诉用户、可以改描述重试，不要假装画好了；
- 出图后宿主自动发出，不用再调 say_media；只有回执说自动发送失败时才用 say_media 补发。
