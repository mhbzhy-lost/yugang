## 查 LoRA（角色 / 画风）

不传 keyword（或传 lora）返回一张**平铺总表**：`key · 名字 · 建议权重`。角色、画风、
以后新增的 LoRA 都在同一张表里 —— 要挑 LoRA 就直接查空，不要猜「风格」「角色」这类分类词。

想画某个角色或某种画风，再用它的 key 或中文名查一次，回执会给出：
LoRA 文件名、建议权重、适配底模、来源、触发词、基础外观、官方服装 tag 分段，
以及几条 danbooru 同名词条作参考。

draw 的用法：

- 角色：`character=<key>`，自动挂角色 LoRA 并注入该角色的触发词与基础外观；
- 画风：`style=<key>`，只挂风格 LoRA，不改 prompt；
- 服装：回执里的服装段不会自动注入，想穿哪套就抄进 prompt。

查不到时回执会给「相近的条目」，照着换关键词再查，不要凭记忆编 key。

## 查 danbooru tag

查 tag 的准确写法和热度。中文概念先自己翻成英文再来查（比如「猫耳」→ cat_ears）。
返回最热的十条，热度越高在 prompt 里越有效。查不到就换近义词。
