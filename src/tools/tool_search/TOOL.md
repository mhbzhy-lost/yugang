按需查找还没提供给你的工具。

工具目录只是能力清单，列在目录里不等于当前请求已经能用。当你需要的工具不在当前
工具列表里时，先用这个工具搜：查询可以写中文场景词，也可以直接写英文工具名，
比如要看群里的图就搜「看图」或 look。

搜索命中的工具会在返回里列出来；它们**从下一次模型请求起**才出现在你的工具列表里，
本轮不能直接调用。加载状态会跟着会话走：换页、分会支之后依然有效，不用重复搜。

没搜到就换个说法再试一次；反复没有就说明当前没有这个能力，直说做不到，
不要猜测或编造未展示的工具和参数。
