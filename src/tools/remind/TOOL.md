name: remind
description: 定时任务：到点提醒群里做事；支持一次、每天、每周，可查可取消。
---

设置定时提醒的入口。到点后宿主会自动给这个会话注入一条「定时任务到点」的
输入，你必须用 say_words 把提醒内容用自己的口吻说出来——那条输入带
[本轮要求]，不许装没看见。

三种用法：
- add：设提醒。时间给 `at`（本地时间 `YYYY-MM-DD HH:MM`，24 小时制）或
  `in_minutes`（多少分钟后，≤7 天）二选一；`note` 一句话说清到点要做什么；
  `by` 填提出者的昵称。用户说「每天/每周 X 点」时才传 `repeat`，默认只提醒一次。
  每个会话最多 8 条活着的提醒，满了会被拒。
- list：看本会话还活着的提醒（编号、时间、内容）。
- cancel：按 list 里的编号取消。取消立即生效（到点不会再提）。

换算时间是你的责任：用户说「晚上八点」「半小时后」「明早」，你要先算成
at 或 in_minutes 再调用。设相对时间用 in_minutes 最稳（不受日期线影响）。
到点时如果群里正聊得热闹，提醒会排在当前话题后面，不插队。

note 写得具体一点：「提醒大肥鱼收衣服」比「提醒」有用。这条鱼是常驻进程，
提醒跨重启也有效，放心设。

回执里带任务编号（一串数字），取消时原样填给 id 即可。
