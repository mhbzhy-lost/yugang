---

调用百炼 Token Plan 的 `wan2.7-image` 生成图片。用户消息出现 **wan-image**（大小写不限），或明确要求使用 Wan/万相云端画图时，必须使用本工具；不要改用 `draw`、`qwen_draw` 或 `gpt_image`。

## 先把用户需求翻译成参数

工具参数不是让用户学习 API，而是把自然语言需求映射成下面三类选择：

### 1. 单张图片：默认模式

用户说“画一张”“生成一张”“做个头像/海报/插画/场景”，或者只描述一个画面时：

- 只传 `prompt`；
- 不传 `enable_sequential`；
- 不传 `n`，默认生成 1 张；
- 不要为了“多给几张”擅自传 `n`，除非用户明确要多张候选图。

例：

```text
用户：wan-image 画一只戴红围巾的橘猫
调用：prompt="一只戴着红色围巾的橘猫……"
```

### 2. 多张候选图：普通多图模式

用户明确说“给我几张不同方案”“生成 3 张候选”“多来几张类似的”，但没有要求故事连续、角色跨图一致时：

- `enable_sequential` 不传或设为 `false`；
- `n` 设为用户要求的数量，最多 4；
- prompt 说明要“不同构图/不同方案”，避免模型把它理解成连续组图。

### 3. 一张图里的多格漫画：仍然是单图模式

用户说“四格漫画”“六格漫画”“漫画分格”“一张图里有多个格子”，意思通常是**一张图片内部排版多个格子**，不是返回多张图片：

- 不传 `enable_sequential`；
- 不传 `n`；
- 在 prompt 开头明确写“单张图片、四格漫画排版”或“单张图片、六格漫画排版”；
- 写清格子数量、阅读顺序（从左到右/从上到下）、每格画面、角色动作和对白；
- 要求格子之间有清晰边框、留白分隔，避免模型把多个场景混成一张连续大场景；
- 如果要图中文字，逐格写明对白并加引号；
- 这类需求不要开启 `enable_sequential`，因为组图模式会返回多张独立 PNG。

示例：

```text
用户：wan-image 画一个猫咪加班的四格漫画
调用 prompt：单张图片，四格漫画排版，2×2 等大格子，白色清晰边框，从左到右、从上到下阅读。第一格：橘猫打开电脑……；第二格：橘猫疯狂敲键盘……；第三格：橘猫趴在桌上睡着……；第四格：橘猫端着咖啡继续工作。每格角色外观和画风一致，格子之间有明显留白分隔。对白分别写着“今天一定早下班”“怎么又加需求了”“困死了”“明天一定早下班”。
```

### 4. 连续组图：组图模式

用户出现以下意图时，使用组图模式：

- “四季组图”“成长过程”“从早到晚”“连续几张”；
- “同一个角色在不同场景”“保持人物/猫的外观一致”；
- “分镜”“故事板”“漫画分格”“一组前后连贯的图”；
- 明确要求“组图”或“连续组图”。

调用时：

- `enable_sequential: true`；
- `n` 设为用户要求的张数，最多 12；
- prompt 必须写清每一张的场景/阶段，并强调主体外观、画风和设定保持一致；
- 用户只说“做一组”但没说数量时，默认 `n: 4`；
- 组图模式不是“随机多张”，而是让多张图片共享故事和主体设定；
- **组图模式不是一张图里的四格漫画**：它返回多张独立 PNG。

例：

```text
用户：wan-image 做一组橘猫四季图
调用：
{
  "prompt": "生成四张同一只橘猫的四季连续组图：第一张春天在樱花树下，第二张夏天在池塘边，第三张秋天踩在落叶上，第四张冬天在雪地里；四张图保持猫的外观、毛色和画风一致。",
  "enable_sequential": true,
  "n": 4
}
```

## 尺寸 `size`

只有用户明确提出尺寸/清晰度需求时才传；否则让模型默认选择：

- `1K`：日常分享、头像、表情、GIF 素材，速度和体积更省；
- `2K`：海报、壁纸、需要裁切或更清晰的图片；
- 只允许 `1K` 或 `2K`，不要传 `1024*1024`、`2048*2048` 等自定义字符串；
- 普通版不开放 4K，也不要向用户承诺 4K。

组图默认优先使用 `1K`，因为一次会生成多张，体积和耗时会随数量增加。

## prompt 写法

- 用自然语言完整描述，不要写 ComfyUI 节点、工作流、模型名或 API 参数；
- 写清主体、动作、环境、时间、光线、镜头和画风；
- 组图要用“第一张/第二张/第三张……”明确分配每张内容；
- 组图需要跨图一致时，重复关键主体特征（毛色、发型、服装、配饰、年龄、画风）；
- 用户要图片里的文字时，明确写出文字内容、位置和字体风格；
- 中文或英文均可，prompt 控制在 800 字以内。

## 硬边界

- 固定使用普通版 `wan2.7-image`，模型不开放给鱼选择；
- `watermark` 默认关闭且不开放；
- `seed` 由工具内部随机生成，不开放；
- `thinking_mode` 使用服务端默认值且不开放；
- `bbox_list`（框选交互编辑）和 `color_palette`（精确色板）是高级功能，不开放；
- 每轮最多调用一次；普通模式 `n` 最多 4，组图模式 `n` 最多 12；
- 图片生成后工具会自动发出，不要再调用 `say_media`；
- 提交状态不明时不要重试，避免重复扣额度；
- 只有用户点名 Wan/`wan-image` 时才使用本工具。
