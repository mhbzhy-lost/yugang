收弹药入库专用：后台定时起的逛 B 站工时轮（worker 轮），或主人私聊里的手动逛轮——
先 bili_hot / bili_video 把候选看完，再把挑中的正式收进弹药库。只有这两种轮里可用：
群聊、别人的私聊、没有逛上下文的普通轮调它只会被拒。

宿主会替你做的事（你不用也不必重复做）：
- 核对 BV 号形状，经 B 站接口补全标题等卡片字段——标题以宿主核到的为准
- 判重：同一个 BV 不管什么状态都进不了第二次，别重复提交
- 限额：一轮收满配额后再提交会被拒，配额多少轮开始时就定了

你要做的事：summary 用你自己的话写这条视频讲什么、为什么值得分享——它是以后
开窗分享时的推荐语底稿，别抄标题、别抄简介原文。topic 按内容归入四个枚举之一，
拿不准就选最贴近的。
